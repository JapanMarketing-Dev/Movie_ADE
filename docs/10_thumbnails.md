# 10. サムネイル（画像生成）

最終更新: 2026-10-11

## 方針

- Claude Code は画像を生成できないので、**画像生成は別の経路**（Codex、Gemini、各社の API、ローカル）で行う。編集の担当が Claude Code でも、サムネイルだけ Codex に頼めるようにする
- 生成モデルには**背景・人物・演出だけ**を作らせる。**日本語のタイトル文字は、別のレイヤーとして確実に合成する**（生成モデルの文字は、誤字や字形の崩れが出ない保証がないため）
- 素材は動画のフレームを使う（顔がはっきり写っている場面、表情の良い場面）

## 流れ

```
① solocut thumb candidates
   動画から候補フレームを選ぶ。判定モデルが「目が開いている、ブレていない、表情が良い」をスコアにする
② solocut thumb gen --frame 00:03:12:05 --n 3
   候補フレームを参照画像として、画像生成で背景・人物・演出を作る（3案）
   方向性はテンプレートの prompts/thumbnail.md に書く
③ 文字の合成
   タイトル（エージェントが短い見出しを作る）を、テンプレートの文字スタイル（書体、縁取り、座布団、配置）で合成する
④ 判定モデルが確認する（文字が読めるか、顔に重なっていないか、小さく表示しても分かるか）
⑤ renders/thumbnails/ に書き出す（YouTube 用 16:9、Shorts・TikTok 用 9:16）
```

## 画像生成の経路

`settings.json` の `imageGen.order` の順に試し、失敗したら次へ切り替える（[11](./11_settings.md)）。

| 経路 | 方法 | 費用 | 注意 |
|---|---|---|---|
| **Codex**（ChatGPT のサブスクリプション） | `codex exec '$imagegen …' -i <参照フレーム>`。gpt-image-2 で生成し、`~/.codex/generated_images/` から取り込む | Plus 以上なら追加費用なし（Codex の利用枠を消費。通常の3〜5倍） | Free プランでは使えない。枠が残っていても 429 が出る不具合の報告があるため（2026-10 時点）、次の経路への切り替えが必須 |
| **Gemini** | Gemini CLI の公式拡張 nanobanana（Nano Banana 2 / 2.1） | 拡張は API キーが必要（画像出力には無料枠なし） | Google のサブスクリプションのログインだけで画像を生成できるかは未確認。実装時に検証し、できなければ API キーの経路として扱う |
| OpenAI API | Images API（gpt-image-2）。`edits` で参照画像を渡す | 1枚あたり約 $0.17〜0.21（high） | 1536×1024 などで作って縮小する |
| Google Gemini API | Nano Banana 2.1 / Pro | 1枚あたり約 $0.07〜0.24 | Imagen 4 と gemini-2.5-flash-image は提供終了（予定）なので使わない |
| その他の API | Ideogram（文字に強い）、FLUX.2、Recraft、fal.ai / Replicate 経由 | 各社 | API キーは OS の保管庫に入れる |
| ローカル | ComfyUI＋Qwen-Image など | 無料（GPU が必要） | 任意 |

## 文字の合成

- テンプレートに文字のスタイルを宣言する（書体、太さ、文字色、縁取り（二重も可）、座布団（背景の帯）、影、配置のパターン）
- 描画は Solocut 自身が行う（SVG を組み、画像に変換して重ねる）。同梱の OFL フォントを使うので、どの OS でも同じ見た目になる
- 文字だけを差し替えて、A/B 案を量産できる
- オプションとして「文字も生成モデルに描かせる」を選べる。その場合は OCR でタイトルと照合し、違っていたら作り直すか、合成に切り替える

## 出力の仕様

| 出力先 | 仕様 |
|---|---|
| YouTube（通常） | 16:9、1280×720 以上（作業は 2K、書き出しは 1920×1080 の JPG）。2MB 以下にする（モバイルからの差し替えにも使えるように） |
| YouTube Shorts | 9:16、1080×1920（設定できるのはパソコンの Studio からのみ） |
| TikTok | API ではカバーを「動画内の時刻」で指定する。そのため、選んだサムネイルを動画の冒頭の数フレームに入れる案も、テンプレートで選べるようにする |

YouTube の Test & Compare（最大3案、通常の動画のみ）に合わせて、既定で3案を作る。
