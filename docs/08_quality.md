# 08. 品質・テスト・リスク

最終更新: 2026-10-11

## テストの方針

- **E2E は作らない。** 画面は人が見て、フィードバックを受けて直す
- その代わり、すぐに回せる**単体テストと結合テストを大量に入れる**。境界値と異常系を必ず含める
- テストの実行環境は vitest（Node）。CI では3つのOSすべてで、型検査と単体・結合テストを回す

## テストの対象と例

| 対象 | 種類 | 例（境界・異常を含む） |
|---|---|---|
| `core`: タイムラインと ops | 単体 | 0フレームの区間、in と out が逆、元素材の範囲外、区間の重なり、undo / redo の往復で元に戻るか、スキーマに合わない JSON |
| `core`: コンパイラ | 単体（ゴールデン） | timeline → RenderPlan の出力を固定のファイルと比べる。レイアウトの切り替え、字幕のない区間、モザイクとリフレームの順序 |
| `media`: 同期 | 結合（ffmpeg で合成した素材） | 既知のオフセット（0、±1フレーム、±10分、範囲外）を復元できるか。無音、ノイズのみ、繰り返し音（信頼度が低いと判定されるか）、ドリフト（1.00002）を推定できるか |
| `media`: 解析 | 結合 | `testsrc` と `sine` で作った黒コマ・フリーズ・無音入りの素材で、検出の結果がフレーム単位で合うか |
| `media`: 書き出し | 結合 | 短い合成素材を書き出し、ffprobe で解像度・fps・コーデック・長さ・ラウドネスを確認する。区間キャッシュが、変更した区間だけを作り直すか |
| `captions` | 単体 | BudouX による改行、1行の文字数の上限、句読点だけの行が出ないか、英数字の混在、ASS のエスケープ（`{` や `\`）、単語の時刻が逆転しているときの扱い |
| `decide` | 単体 | プロバイダごとの変換、しきい値の境界（ちょうど 0.3 / 0.7）、費用の上限を超える直前と直後、タイムアウト、壊れた応答、キャッシュの当たり外れ |
| モザイク | 結合 | 動く四角を描いた合成素材で、追跡とモザイクがはみ出さないか。レイアウトを変えても対象についていくか |
| `toolchain` | 単体 | ハッシュ値の不一致、署名の不正、ダウンロードの中断と再開、ディスクの空きがない場合 |
| `agents` | 単体 | 起動コマンドのクォート（posix / PowerShell / cmd）、使用量の上限の文言の検出（誤検知しないか） |
| `templates` | 単体 | 継承、スキーマの検証、`solocut next` の状態遷移（合格条件の境界） |
| 配布 | 単体 | latest.json / manifest の検証、署名の検証の失敗、バージョンの比較 |

合成素材は、テストの中で ffmpeg の `lavfi`（`testsrc2`、`sine`、`anoisesrc`）で作る。大きな動画ファイルはリポジトリに入れない。

## リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| MediaRecorder の映像が可変フレームレート | カットやチェックがフレームの位置でずれる | 取り込み時に固定フレームレートの編集用素材を作る。元のファイルは残す |
| PCの音声のループバックが OS や Electron のバージョンで動かない | PCの音声が録れない | 3つのOSで確認し、だめな環境では BlackHole（mac）などを案内する |
| whisper が言いよどみを文字に起こさない | 言いよどみのカットが漏れる | initial prompt と、単語の間の音声のエネルギーで補う |
| 日本語の単語の時刻が粗い | 単語ハイライトがずれる | WhisperX のアライメント（オプション）。標準では文節単位のハイライトにする |
| 判定モデルの費用 | 長尺で高くなる | 機械的チェックを先に行い、フレームの選び方を絞る。上限とキャッシュを設ける。ローカル（Ollama）も選べる |
| 判定モデルの誤判定 | 必要な部分を切る、問題を見逃す | 中間の確率は人に回す。元の素材と操作の履歴があるので、いつでも戻せる |
| モザイクの追跡外れ | 個人情報が一瞬映る | 範囲を大きめに取る、信頼度の低いフレームは広げる、`mosaic-tracking` でフレーム単位に確認する |
| Remotion のライセンス | 企業の利用者が知らずに使う | インストール時に同意を取る。HyperFrames / Revideo を先に案内する |
| FFmpeg の GPL と特許 | ライセンス上の問題 | 別プロセスで呼ぶ、配布は上流から直接、ライセンスの表示 |
| macOS の署名がないと自動更新が動かない | mac の利用者が更新できない | Apple Developer Program に登録して署名・公証する |
| Windows の SmartScreen の警告 | 初回のインストールで不安を与える | サイトで手順を案内する。利用者が増えたらコード署名を検討する |
| 長尺の書き出しが遅い | 待ち時間が長い | 区間ごとの並列エンコード、ハードウェアエンコーダー（VideoToolbox / NVENC / QSV）をプレビューで使う |
