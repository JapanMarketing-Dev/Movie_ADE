# 01. コンセプトと要件 — Solocut

最終更新: 2026-10-11

## 一言で

**1人で撮って、ターミナルのAIエージェントがテンプレートどおりに編集し、判定モデルがフレーム単位で最終チェックする、YouTube / TikTok 向けの動画編集ADE。**

無料、MITライセンス、macOS / Windows / Linux の3プラットフォームで動く。

## 誰のためか

- 撮影から投稿までを1人でこなすクリエイター（解説、トーク、画面収録のチュートリアル、Vlog）
- 編集ソフトのタイムラインを長時間触りたくないが、品質は落としたくない人
- Claude Code / Codex などのサブスクリプションをすでに持っている人。追加課金なしで、そのサブスクリプションを編集の頭脳として使う

対象外: 複数人での共同編集、会議（MTG）の録画、クラウド上でのレンダリング、YouTube / TikTok への直接アップロード（タイトル・説明文・チャプターなどのメタデータファイルを出すところまでやる）。

## 解決したい課題

| 課題 | Solocut の答え |
|---|---|
| 1人だと撮影と編集の両方に時間がかかる | 撮影（画面・カメラ・マイクの同時収録）から書き出しまでを1つのアプリで完結させる |
| AIに編集を頼んでも、毎回やり方がばらばらになる | **テンプレート**で、フォーマット・レイアウト・カット方針・字幕スタイル・チェック項目・作業手順を固定する。エージェントはテンプレートの手順どおりに動く |
| GUIの編集ソフトはAIエージェントから操作しにくい | 編集の正本は `timeline.json` というテキストにする。エージェントは `solocut` CLI で編集する。ターミナルだけで完結する |
| AIの編集は細部（一瞬の黒コマ、口の途中で切れたカット、字幕のはみ出し、映り込んだ個人情報）が怪しい。モザイク処理も手間がかかる | **decision model（判定モデル）** が、カットの境目のフレームや字幕のフレームを1枚ずつ判定する。自信が低いものだけを人に回す |
| 修正の指示を文字で書くのが面倒 | 書き出したプレビューを見ながら**喋ってペンで囲むだけ**で、タイムコード付きの修正指示に変換してエージェントへ送る |

## 体験の流れ

```
① テンプレートを選んでプロジェクトを作る（例: TikTok 縦型トーク）
② 撮る: 画面＋カメラ＋マイクを同時収録（別撮りのカメラ素材は、あとから取り込んで自動で同期）
③ エージェントのターミナルで「編集して」と言う
   → エージェントは `solocut next` でテンプレートの次の手順を確認しながら進める
      取り込み → 同期 → 文字起こし → 粗カット → 字幕 → レイアウト → プレビュー → チェック
④ decision model が、カットの採否と字幕の改行・強調を判定し、最後にフレーム単位でチェックする
   （自信が低いものは「要確認」の一覧に出す）
⑤ 人がプレビューを見て、喋りながらペンで囲む → 修正指示がエージェントへ届く → 直る
⑥ 本番の書き出し（YouTube 16:9 / TikTok 9:16 / Shorts / Reels）。メタデータファイルも出す
```

## 機能要件

### 撮影（REC）

| ID | 要件 |
|---|---|
| REC-1 | 画面（ディスプレイ全体／ウィンドウ）、カメラ、マイク、PCの音声を**同時に、別々のトラック（別ファイル）として**収録する。あとからテンプレートでレイアウト（ワイプ、上下分割、カメラのみ、画面のみ）を切り替えられるようにするため |
| REC-2 | カメラとマイクは複数台を選べる。カメラの解像度とfpsを指定できる |
| REC-3 | 全トラックの開始時刻を同じ時計で記録し、トラック間のズレをフレーム単位で揃えられるようにする |
| REC-4 | 収録中のファイルは数秒ごとにディスクへ書き出す。アプリが落ちても直前までの映像が残る |
| REC-5 | 撮影補助: カンペ（台本プロンプター）、カウントダウン、録画中の目印ホットキー（「今のNG」「ここ重要」）。目印は編集時にエージェントと判定モデルが使う |
| REC-6 | テイク管理: 1つのプロジェクトに複数のテイクを撮り足せる |
| REC-7 | 同期マーカー: 収録開始時に画面のフラッシュとビープ音を出す（オプション）。別撮りカメラとの同期の補助に使う |

### 取り込みと同期（IMP）

| ID | 要件 |
|---|---|
| IMP-1 | 別撮りのカメラ（ミラーレス、iPhone など）や外部レコーダーのファイルを、既存のテイクにトラックとして追加する |
| IMP-2 | 音声波形の相互相関で、自動的にフレーム単位で同期する。同期の確からしさ（信頼度）も出す |
| IMP-3 | 長尺では機材ごとの時計のズレ（ドリフト）を検出して補正する |
| IMP-4 | fps・解像度・可変フレームレート（VFR）が混ざっていても、編集用に正規化する |
| IMP-5 | 信頼度が低い場合は判定モデルと人の確認に回す。手動でのオフセット調整もできる |

### 編集（EDIT）

| ID | 要件 |
|---|---|
| EDIT-1 | カット: 無音、言いよどみ（「えー」「あのー」）、言い直し、NG目印の区間を候補として出し、判定モデルが採否を決める |
| EDIT-2 | 字幕: 単語単位のタイムスタンプから字幕を作る。日本語の自然な改行、強調語、TikTok風の単語ハイライト、セーフエリアに合わせた配置 |
| EDIT-3 | レイアウト: テンプレートのレイアウトを区間ごとに切り替える（例: 画面操作中はワイプ、話しているだけのところはカメラのみ） |
| EDIT-4 | 縦型リフレーム: 16:9 の素材から、顔を追いかけて 9:16 に切り出す |
| EDIT-5 | 音声: ラウドネス正規化（-14 LUFS / -1 dBTP）、BGM、話している間のBGM自動ダッキング、ノイズ除去 |
| EDIT-6 | 挿入素材: タイトル、テロップ、画像、効果音。モーショングラフィックスは外部ライブラリ（Remotion など）で作ったクリップを重ねる |
| EDIT-7 | 長尺から縦型ショートの切り出し（見どころの候補を判定モデルが出す） |
| EDIT-8 | すべての編集は操作ログとして記録し、元に戻す・やり直す・差分を見ることができる。元の素材は絶対に書き換えない |
| EDIT-9 | **モザイク・ぼかし**: 画面に映った個人情報（メールアドレス、通知、APIキー、住所、電話番号）、第三者の顔、ナンバープレートなどを自動で検出して追跡し、モザイク／ぼかし／塗りつぶしをかける。手動で範囲を囲んで追加することもできる。かけ忘れは判定モデルがフレーム単位で確認する |

### チェック（CHK）

| ID | 要件 |
|---|---|
| CHK-1 | 機械的チェック: 黒コマ、フリーズ、無音、ラウドネス、クリップノイズ、解像度・fps・コーデック・長さが出力先の仕様に合っているか |
| CHK-2 | フレーム単位の判定: カットの境目の前後のフレーム（瞬きや口の動きの途中で切れていないか、1〜2フレームの切れ残りがないか）、字幕のはみ出しや顔・重要部分との重なり、画面に映った個人情報（通知、メールアドレス、APIキー）、モザイクのかけ忘れ・追跡外れ |
| CHK-3 | チェック結果はレポート（Markdown＋フレーム画像）としてエージェントに渡り、エージェントが直す。合格するまで繰り返し、自信が低いものだけを人に回す |

### フィードバック（FB）

| ID | 要件 |
|---|---|
| FB-1 | プレビューを再生しながら、喋る・ペンで囲む・止めて書く、ができる |
| FB-2 | 指摘ごとに「タイムコード、フレーム画像（ペン入り）、発話、その時点のタイムライン上の要素（どのクリップ・どの字幕か）」に分解する |
| FB-3 | 分解結果を確認・修正してから、1ボタンでエージェントへ送る |
| FB-4 | 動画と音声は端末から出さない。文字起こしは端末内で行う |

### エージェント（AG）

| ID | 要件 |
|---|---|
| AG-1 | Claude Code、Codex、Gemini CLI、OpenCode など複数のエージェントCLIを、アプリ内のターミナルで起動し、タブで切り替えられる。独自のコマンドも登録できる |
| AG-2 | どのエージェントでも同じテンプレート・同じ手順で動くよう、プロジェクトに指示書（`AGENTS.md` / `CLAUDE.md`）を自動生成する |
| AG-3 | エージェントを切り替えても作業が続くよう、状態はすべてプロジェクトのファイルに置く（`solocut status` で誰でも現状が分かる） |
| AG-4 | 使用量の上限に達したら、別のエージェントへ引き継げる |
| AG-5 | エージェントCLI自体の更新を検知し、ワンクリックで更新できる |
| AG-6 | `solocut` CLI はアプリなしでも単体で動く（ヘッドレス、CIでも利用可能） |

### ライブラリ（LIB）

| ID | 要件 |
|---|---|
| LIB-1 | 動画編集ライブラリ・ツールを、必要なときにダウンロードして使う（ffmpeg、whisper.cpp、Remotion、HyperFrames、Revideo、WhisperX、MediaPipe など） |
| LIB-2 | ダウンロードしたものはハッシュ値で検証し、バージョンを固定する。オフライン環境向けに、手元のファイルを指定して入れることもできる |
| LIB-3 | 利用条件に注意が必要なもの（Remotion の企業ライセンスなど）は、インストール前に条件を見せて同意を得る |

### 配布と更新（DIST）

| ID | 要件 |
|---|---|
| DIST-1 | Cloudflare（Pages のサイト＋R2）からダウンロードできる。ドメインは `solocut.app` |
| DIST-2 | アプリを自動で更新する。更新の情報には署名を付け、改ざんされたものを入れない |
| DIST-3 | ツール類（ffmpeg など）の推奨バージョンも、署名付きのマニフェストで更新する |

## 非機能要件

| ID | 要件 |
|---|---|
| NF-1 | 無料。サーバー費用がほぼかからない構成にする（静的サイトと R2 のみ。処理はすべて端末内） |
| NF-2 | プライバシー: 動画・音声は既定で端末から出さない。判定モデルにクラウドを使う場合は、送るのはフレーム画像と文字起こしだけで、送る前に明示して同意を得る。完全ローカルの判定モデル（Ollama）も選べる |
| NF-3 | 書き出しの再現性: 同じ `timeline.json` と同じツールのバージョンからは、同じ結果が出る |
| NF-4 | 長尺対応: 2時間の素材でも、プレビューはキャッシュで高速に作り直せる |
| NF-5 | 日本語と英語のUI |
| NF-6 | テスト: E2Eは作らない。境界と異常を含めた単体・結合テストを大量に入れる（[08](./08_quality.md)） |

## 名前とドメイン

- 名前: **Solocut**（solo＋cut。1人で撮って切る）
- ドメイン: `solocut.app`（主）、`solocut.dev`（任意）。2026-10-11 時点で RDAP 照会で未登録を確認済み。`solocut.com` は登録済み
- CLI: `solocut`、プロジェクトの設定ファイル: `solocut.json`、ユーザーデータ: `~/.solocut/`
