# 12. 既存の編集ソフトとの比較

最終更新: 2026-10-11（Premiere 26.x、CapCut デスクトップ版、DaVinci Resolve 21.1 時点）

## まねる点・まねない点

| ソフト | まねる | まねない |
|---|---|---|
| **Adobe Premiere** | 文字起こしを消すとカットされる仕組み（単語単位の時刻とリップル削除）。フィラーと無音を種類ごとにまとめて削除する機能。1語ずつ出すキャプション（Solocut はさらに、話している語を強調するカラオケ式まで標準で持つ）。OTIO の読み書き。タイムコードと範囲が付いたレビューコメント（Frame.io 型） | クラウドのクレジットに頼る生成 AI。すぐ変わる拡張の API（UXP / ExtendScript）を前提にすること。パネルの多い UI |
| **CapCut** | **テンプレート = 固定のレイヤー＋差し替えられるスロット**という形（クリップ数も可変）。字幕スタイルのテンプレート。長尺からショートを一括で作る機能（長さ・本数・字幕スタイルを指定）。リフレームの設定（手ぶれ補正、追従の速さ） | 利用者のコンテンツを広く使える権利を取る規約や、クラウドへの保存が前提の作り。TikTok だけに寄せた作り。権利関係があいまいな素材ライブラリ |
| **DaVinci Resolve** | IntelliScript の「台本と文字起こしを照らし合わせて一番良いテイクを選び、別のテイクも残す」。話者で画角を切り替える SmartSwitch。素材を1本の帯として流し見る Source Tape。**外部のエージェントを MCP でつなぐ**考え方 | Studio 版（有料）でしか使えない API を前提にすること。GPU メモリ 16GB が必要な重い AI を必須にすること |

## Solocut に取り込むもの

| 取り込むもの | 反映先 |
|---|---|
| 文字起こしの編集でカットする（台本・文字起こしを正本として扱う） | `solocut edit cut-text "…"`：文字起こしの範囲を指定してカットする部品。エージェントは文字起こしを読み、消す文を指定するだけ（[02](./02_architecture.md)） |
| 台本と照らし合わせたテイクの選択 | `script.md` がある場合、各文のテイクの候補を判定モデルが比べて選ぶ。選ばなかったテイクも区間の候補として残す（[05](./05_decision_model.md)） |
| 差し替えスロット型のテンプレート | テンプレートに `slots`（タイトル、見出し、ロゴ、BGM など）を持たせ、差し替える場所を宣言する（[04](./04_templates_and_agents.md)） |
| 長尺からショートの一括作成 | `shorts-from-long` テンプレート。本数・1本の長さ・字幕スタイルを指定する |
| 話者・プロンプトによる画角の切り替え | マルチカメラ（[04](./04_templates_and_agents.md)） |
| タイムコード付きのレビュー | 動画フィードバック（[04](./04_templates_and_agents.md)） |
| **MCP** | `solocut mcp`：Solocut の CLI と同じ機能を MCP サーバーとしても公開する。CLI を呼ぶのが苦手なエージェントや、MCP を前提にした環境でも使えるようにする |
| 他のソフトへの受け渡し | OTIO と FCPXML の書き出し（`solocut export otio`）。仕上げを Premiere / Resolve でしたい人も使える |

## Solocut の違い

1. **編集の正本がテキスト**（timeline.json と文字起こし）。エージェントがそのまま読み書きでき、差分も取れて元にも戻せる。Resolve の MCP は既存のアプリに後から付けたもので、Solocut は最初からエージェント向けに作る
2. **テンプレートとプロンプトで、毎回同じ作り方を強制できる**（`solocut next` と合格条件）
3. **判定モデルによるフレーム単位の検査**と、迷ったものだけを人に回す仕組み
4. **ローカル完結・OSS・コンテンツの権利は利用者のもの**
5. **使うエージェントを選ばない**（Claude Code / Codex / Gemini CLI / その他）。画像生成の経路も1つに縛らない
