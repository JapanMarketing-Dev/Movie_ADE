# 16. 素材ライブラリ（効果音・BGM・イラスト・アニメーション）

最終更新: 2026-10-11（各サイトの規約は 2026-10 時点の調査。規約はよく変わるので、規約の要約は配信する JSON で更新する）

## 方針

- **使い回す前提**。毎回素材を探さない。よく使う効果音・BGM・イラスト・アニメーションを最初からそろえ、テンプレートとシーンのパターン（[15](./15_timeline_schema.md)）から決まったものを使う
- 素材の扱いは、規約によって3つに分ける

| 区分 | 条件 | 扱い |
|---|---|---|
| **A. 標準ライブラリ**（都度ダウンロード） | CC0、CC BY、MIT / Apache などで**再配布が許されている**もの | Solocut が R2 で配る。**最初にまとめて入れず、必要になったときに、その素材だけをダウンロード**する。クレジットが必要なものは自動で表記を作る |
| **B. 自分で取り込む** | 利用は無料だが**再配布は禁止**のもの | アプリ内のブラウザで公式サイトを開き、利用者が自分でダウンロードしたものを、ライブラリに自動で取り込む。Solocut はファイルを集めない・配らない |
| **C. 連携しない** | アプリとの連携・組み込みを規約で禁止している、または事前の相談が必要なもの | ボタンを置かない。OS の標準ブラウザで開くだけ。運営の許可が取れたら B に移す |

## 都度ダウンロードの仕組み

アプリには素材の**目録だけ**を持たせ、素材のファイルは必要になったときに1つずつ取りに行く。

- 目録（`library-catalog.json`、署名付き）: 素材ごとの id、カテゴリ、タグ、長さ、ライセンス、ハッシュ値、R2 の場所、試聴用の短いプレビュー（数 KB）。検索・試聴・選択は目録だけでできる
- ダウンロードのきっかけ:
  - エージェントが `solocut sfx use pop_03` / `solocut bgm use lofi_02` などで素材を使うと決めたとき
  - 人が素材の画面で「使う」を押したとき
  - テンプレートやシーンのパターンが既定で使う素材を、書き出しの直前に確認したとき
- ダウンロードしたものは `~/.solocut/library/cache/` に置き、ハッシュ値で検証する。同じ素材は二度と取りに行かない（使い回し）
- キャッシュは容量の上限（既定 2GB）を超えたら、最近使っていないものから消す。**使っているプロジェクトがある素材は消さない**
- オフラインのときは、キャッシュにある素材だけで編集を続け、足りない素材は「要ダウンロード」の印を付けて書き出しの前に知らせる

## 効果音・BGM

### A. 標準ライブラリ（都度ダウンロード）

| 素材元 | ライセンス | 入れるもの |
|---|---|---|
| Kenney（Interface / UI / Impact / Jingles など） | CC0 | クリック、通知、ポン、ドン、正解・不正解、ジングル |
| OtoLogic | CC BY 4.0（表記必須:「効果音提供 オトロジック(https://otologic.jp)」） | 厳選した数十〜100音（シュッ、キラーン、ピコーンなど）。**同梱前に公式の規約を人が確認する** |
| Freesound / OpenGameArt の CC0 | CC0 | 手作業で選んだタイピング音、ページめくり、whoosh（API で集めたものは R2 に置かない） |
| **Solocut 自作** | CC0 | シンセで作る whoosh、ピコーン、キラーン、ズーム音。Content ID の心配がない |
| BGM | 自作・作曲依頼の **CC0**（5〜10曲：Lo-fi、解説向けの落ち着いた曲、アップテンポ）＋ Kevin MacLeod（CC BY 4.0）の数曲 | 技術動画・語り動画向け |

- 規模の目安: 効果音 200〜400個、BGM 10曲（全部で 50〜70MB）。ただし**まとめてはダウンロードしない**

### B. 自分で取り込む

Pixabay、Mixkit、Uppbeat（クレジット必須）、魔王魂（クレジット必須）、甘茶の音楽工房、ポケットサウンド（クレジット必須）、YouTube オーディオ ライブラリ（YouTube でのみ使える）など。

- ダウンロードするのは利用者。Solocut はダウンロードの完了を検知して取り込み、どのサイトの素材かを記録する
- **やらないこと**: ページのスクレイピング、ファイルの URL の組み立て、一括ダウンロード、直リンク

### C. 連携しない

効果音ラボ（アプリへの組み込みを再配布とみなす）、OpenTracks（旧 DOVA-SYNDROME。ツールへの組み込みは事前相談が必要）、Springin' Sound Stock、On-Jin（アプリからの URL の直接指定を禁止）。

## イラスト・アイコン・アニメーション

### A. 標準ライブラリ（都度ダウンロード）

| 種類 | 素材元 | ライセンス | 使いどころ |
|---|---|---|---|
| **人物の線画** | Open Peeps、Open Doodles | CC0 | 解説シーン（`explain-illust-bubbles`）の人物。**白線に変換した版**も用意し、黒背景にそのまま使えるようにする |
| 人物（カラー） | Humaaans | CC0 | 明るい図解 |
| アイコン | Lucide、Tabler、Phosphor、Heroicons、Material Symbols、game-icons | ISC / MIT / Apache-2.0 / CC BY 3.0 | 箇条書き、比較、図解 |
| 絵文字 | Fluent Emoji（3D あり）、Twemoji、Noto Emoji | MIT / CC BY 4.0 / Apache-2.0 | リアクション、強調 |
| 絵文字（線画） | OpenMoji | CC BY-SA 4.0（改変したものは同じライセンスで公開する義務があるので、別に管理する） | 黒背景向けの線画の絵文字 |
| アニメーション | Noto Animated Emoji（Lottie）、Rive Community（作品ごとに作者を記録） | CC BY 4.0 | 動くリアクション |
| 公共系 | デジタル庁のイラスト・アイコン | 政府標準利用規約（加工して出す場合は出典と編集内容を明示） | 日本向けのピクトグラム |
| テクスチャ | ambientCG、Poly Haven | CC0 | 背景の質感 |
| **背景・枠・吹き出し・ワイプの縁取り・テロップの座布団** | **Solocut が自分で生成する**（SVG ＋シェーダ。MIT） | MIT | 波模様の背景、グラデーションの枠、吹き出し（しっぽの位置・角丸・線幅を指定できる）、丸ワイプの縁取り。日本のテロップ素材サイトはどこも再配布を禁止しているため、外部の素材に頼らない |

**ブランドロゴ（GitHub、Python など）は標準ライブラリに入れない。** 著作権が CC0 や MIT でも商標権は別に残り、改変や商用での利用に条件があるため。技術動画で使う場合は、利用者が取り込むか、注意書き付きの任意のパックにする。メタデータで「改変しない、色は公式の色だけ」と縛り、サムネイルの主役にしたり提携を思わせたりしないよう注意を出す。

### B. 自分で取り込む（日本のイラスト素材）

| 素材元 | 画風 | 注意 |
|---|---|---|
| **いらすとや** | カラーのフラットな手描き（黒背景では白いフチを付ける） | **1つの制作物につき20点まで**（重複は1点、表情違いは別の点、色違いは1点）。21点以上は有料。アプリへの収録は禁止 |
| **Loose Drawing** | **線画で黒背景向き** | 素材そのものの再配布は禁止 |
| **Linustock** | **ビジネス系の線画で黒背景向き** | テンプレートでの配布は禁止 |
| ソコスト | シンプルな線とフラット。アニメーション化は可 | **生成 AI への入力は禁止** |
| ちょうどいいイラスト | カラーのフラット | 直リンクは禁止。AI の学習は禁止 |
| ぴよたそ | ゆるい手描き | ― |
| ICOOON MONO | モノトーンのアイコン | ― |
| イラストAC / シルエットAC | さまざま／シルエット | 本人のログインが必要。無料会員は1日10点まで。**ソフトウェアによるダウンロードは禁止**。生成 AI への入力も禁止 |

取り込みの決まり:

- 公式サイトをそのまま表示し、ダウンロードは**本人がクリック**する。Solocut はダウンロードフォルダを監視して取り込むだけ
- **やらないこと**: 一覧のスクレイピング、それを使った独自の検索画面、自動のクリック・一括ダウンロード、サムネイルの直リンク
- **再配布にならないようにする**: 取り込んだ素材が入ったプロジェクトをテンプレートとして書き出すときは、その素材を除く（またはブロックする）
- **AI に渡さない**: 生成 AI への入力を禁止している素材（ソコスト、ちょうどいいイラスト、AC 系）には `aiInputProhibited` の印を付け、画像生成（[10](./10_thumbnails.md)）や判定モデルに渡さない

### いらすとやの点数を数える

- 単位は「1本の動画（サムネイルを含む）」。素材の id で重複を除き、表情違いは別の点、色違いは1点として数える
- 18点で警告し、21点目は書き出しの前に確認する
- シリーズものを「1つの商品（番組）」とみなす場合に備え、**シリーズ単位で合計する**設定を選べる
- 収益化しない動画では上限がないため、「収益化しない」の設定で制限を外せる
- 同じ仕組みで、ほかの素材元の点数制限（例: フキダシデザインの「1アプリにつき20素材」）も扱う

### C. 連携しない・同梱しない

unDraw（パックとしての配布やスクレイピングを禁止）、Storyset（ライブラリへの収録を禁止）、DrawKit、Blush、useAnimations、Lordicon、IconScout。LottieFiles の無料アニメーションは、少数を厳選して入れるかどうかを運営に問い合わせてから決める。

## 素材ごとのライセンス情報

素材1つごとに、次の情報を持つ（`~/.solocut/library/index.sqlite` と、ファイルの横の JSON）。

```jsonc
{
  "id": "sfx_pop_03", "sha256": "…", "kind": "sfx", "category": "pop",
  "title": "Pop 3", "author": "Kenney", "sourceSite": "kenney.nl", "sourceUrl": "https://kenney.nl/assets/interface-sounds",
  "license": { "spdx": "CC0-1.0", "url": "https://creativecommons.org/publicdomain/zero/1.0/",
               "attributionRequired": false, "redistributable": true, "commercialOk": true,
               "restrictions": [], "limit": null },
  "modification": { "allowed": true, "shareAlike": false, "noDerivatives": false },
  "flags": { "aiInputProhibited": false, "trademark": false, "bundleAllowed": true, "origin": "pack" },
  "contentIdRisk": "low",
  "acquiredAt": "2026-10-11", "tosCheckedAt": "2026-10-11",
  "features": { "durationMs": 180, "lufs": -18.2, "tags": ["ui", "light"] }
}
```

- `restrictions` の例: `no-contentid-registration`、`no-ai-training`、`youtube-only`、`no-game-use`
- `limit` の例: `{ "key": "irasutoya", "perProduction": 20, "scope": "video+thumbnail", "dedupeKey": "irasutoya:businessman_shock" }`
- `origin`: `pack`（標準ライブラリ）／ `user-import`（自分で取り込んだもの）／ `generated`（Solocut が生成したもの）

## 書き出し・投稿時の処理

- **クレジットの自動作成**: タイムラインで使った素材のうち、表記が必要なものについて、各サイトの指定の書式で説明欄用の文を作る（`renders/<target>/credits.txt`。投稿時の説明文にも入れる）
- **警告**:
  - Content ID のリスクが中以上の曲を使ったとき
  - `restrictions` に反する使い方をしたとき（例: YouTube オーディオ ライブラリの曲を TikTok に使った）
  - 点数の上限を超えたとき（例: いらすとやを1作品で21点以上使った）
- **規約の要約の更新**: サイトごとの規約の要約は R2 の `library-terms.json`（署名付き）で配信し、アプリを更新せずに直せるようにする

## 素材の探し方（エージェント向け）

- `solocut sfx search pop --mood light` / `solocut bgm search --mood lofi --bpm 80-100` / `solocut asset search "ビジネスマン 線画"`
- テンプレートの `sfx.rules` と、シーンのパターンのスロット（`hint`）から、エージェントがライブラリを検索して当てはめる
- 新しい素材が必要なときは、エージェントは「どんな素材が要るか」を `.solocut/questions.md` に書き、人が B の方法で取り込む
