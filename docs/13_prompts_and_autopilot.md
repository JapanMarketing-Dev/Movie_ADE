# 13. 用意済みのプロンプトと、1プロンプトでの完成

最終更新: 2026-10-11

## 目指す使い方

```
10〜20分撮る
  → 「動画を完成させて」（1つのプロンプト、またはボタン1つ）
  → エージェントがテンプレートの手順を最後まで進める
     取り込み → 同期 → 文字起こし → カット → マルチカメラの切り替え → 字幕 → 効果音・BGM
     → モザイク → チェック → 書き出し → サムネイル → タイトル・説明文・チャプター
  → 完成の通知。見て気になるところがあれば、喋って囲んで直してもらう
  → 「投稿して」で YouTube / TikTok に投稿し、X / Instagram / Threads / Facebook で告知（[14](./14_publishing.md)）
```

## 用意済みのプロンプト

よく使う依頼をプロンプトとして用意し、エディタのボタンやコマンドパレットからワンクリックで、選んでいるエージェントに送る。

| ID | ボタン | 内容 |
|---|---|---|
| `finish` | 動画を完成させて | 投稿できる状態まで、テンプレートの手順をすべて進める（下のオートパイロット） |
| `rough-cut` | 粗カットだけ | カットまで進めて止まる。人が確認してから続ける |
| `fix-feedback` | フィードバックに対応して | 最新の `feedback/<id>/feedback.md` に対応し、チェックをやり直す |
| `fix-checks` | チェックを全部直して | `solocut check` の不合格をすべて直し、合格するまで繰り返す |
| `captions-polish` | 字幕を整えて | 誤字・用語・改行・強調を見直す |
| `shorts` | ショートを3本作って | 長尺から見どころを選び、縦型のショートを作る |
| `thumbnail` | サムネを3案作って | サムネイルの候補を作る（画像生成は Codex などに回す。[10](./10_thumbnails.md)） |
| `metadata` | 投稿文を作って | タイトルの候補、説明文、チャプター、タグ、SNS の告知文を作る |
| `publish` | 投稿して | 投稿の内容を確認する画面を出し、承認されたら投稿する |
| `announce` | SNSで告知して | X / Instagram / Threads / Facebook に告知を投稿する |
| `english` | 英語字幕も作って | 英語の字幕（SRT）と英語のタイトル・説明文を作る |
| `same-as-last` | 前回と同じ作りにして | 直前の回をアーカイブから参考に登録し、その作りに合わせる（[17](./17_archive.md)） |
| `like-past` | 過去の動画を参考に作って | 選んだ過去の回を参考に登録し、その作りに合わせる（[17](./17_archive.md)） |
| `compare-past` | 過去の回と比べて | 今の動画と過去の回を比べ、違いと改善点を報告する |
| `learn` | 今回の直しをテンプレートに反映して | 今回のフィードバックと人の判断から、テンプレートのプロンプトへの追記を提案する |
| `bench-apply` | ベンチマークを取り込んで | 選んだスタイルプロファイルをテンプレートに取り込む（[09](./09_benchmark.md)） |

## プロンプトは JSON で変えられる

- 組み込みのプロンプトは `prompts.default.json` としてアプリに同梱する
- 利用者は `~/.solocut/prompts.json` で**上書き・追加・非表示**ができる。プロジェクトだけの上書きは `<project>/.solocut/prompts.json`
- 画面からの編集も、この JSON を書き換えるだけ。エージェントに「告知文のプロンプトをもっとカジュアルにして」と頼んでもよい（JSON Schema を公開する。[11](./11_settings.md)）

```jsonc
{
  "$schema": "https://solocut.app/schema/prompts.v1.json",
  "prompts": [
    {
      "id": "finish",
      "label": { "ja": "動画を完成させて", "en": "Finish the video" },
      "agent": "default",                 // default | claude | codex | gemini | custom:*
      "body": {
        "ja": "このプロジェクトの動画を、テンプレート {{template}} の手順に沿って投稿できる状態まで完成させてください。まず `solocut next --json` を実行し、state が done になるまで繰り返してください。人の確認が必要なものは .solocut/questions.md にまとめ、待たずに進められる手順を先に進めてください。最後に、やったことと確認してほしい点を3行で報告してください。"
      },
      "autopilot": true
    },
    {
      "id": "thumbnail",
      "label": { "ja": "サムネを3案作って", "en": "Make 3 thumbnails" },
      "agent": "codex",                   // 画像を作れるエージェントへ送る
      "body": { "ja": "`solocut thumb candidates` で候補を選び、prompts/thumbnail.md の方向性で `solocut thumb gen --n 3` を実行してください。" }
    },
    { "id": "english", "hidden": true }   // 使わないものは非表示に
  ]
}
```

使える変数: `{{project}}`、`{{template}}`、`{{targets}}`、`{{latestFeedback}}`、`{{latestCheck}}`、`{{selection}}`（エディタで選んでいる区間・字幕）、`{{date}}`。

## オートパイロット（1プロンプトで完成）

`finish` を送ると、エージェントは `solocut next` を `done` になるまで繰り返す。人の確認を待たずに最後まで進めるため、次のように振る舞う。

| 場面 | 通常 | オートパイロット |
|---|---|---|
| 判定モデルの答えが中間（迷う） | 人の確認を待つ | **一番確率の高い答えで進め**、「要確認」の印を付けて一覧に残す。完成後に人がまとめて見直せる |
| チェックの不合格 | エージェントが直す | 同じ。3回直しても合格しなければ、印を付けて先に進む |
| 同期の信頼度が低い | 人の確認を待つ | 待つ（ずれた同期は全体を壊すため）。それ以外の手順は先に進める |
| 投稿 | — | **必ず止まる**。投稿は人が承認してから（設定で変えられる） |

```jsonc
// settings.json
"autopilot": {
  "stopBefore": ["publish"],          // ここで必ず止まる
  "maxFixLoops": 3,
  "notify": ["done", "needs-human"],  // OS の通知
  "budget": { "decisionUsd": 2 }      // 判定モデルの費用の上限
}
```

- 進み具合はエディタの上部に、手順ごとのバー（✓ 済み／● 実行中／! 要確認）で表示する
- 完成すると OS の通知を出す。プレビュー、要確認の一覧、サムネイル、投稿文が1画面にそろう
- 10〜20分の素材を前提に、処理時間の目安を最初に表示する（文字起こしとチェックが大半を占める）

## 「毎回同じ作り」を保つ仕組み

- テンプレートのプロンプト（`prompts/*.md`）と、用意済みのプロンプト（`prompts.json`）は、どちらもファイルなので Git で管理できる
- `learn` で、繰り返し出た直しをテンプレートに取り込む。次の動画では、最初からその直しが反映される
- `same-as-last` で、直前の動画の作りを引き継ぐ
