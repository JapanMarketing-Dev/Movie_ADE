# Solocut 0.2.1

## 変わったこと

- **字幕を見やすくしました。** 極太ゴシック・白文字に太い縁取り・1行18字まで。字幕ごとに大事な言葉を1〜2語、黄色で強調します。表示時間は0.8〜4秒に整え、言葉の途中で字幕が分かれないようにしました
- **効果音が入るようになりました。** ダウンロード不要の効果音（ポン・シュッ・ピコーン・クリック・タイピングなど）を最初に自動で用意し、章の頭・ズーム・強調語に、話し声より控えめな音量で入れます（1分に6回まで）
- **お手本動画（編集のベンチマーク）。** 手元の動画、または YouTube / TikTok の URL（アプリ内で再生した部分だけを解析）から、カットの間・字幕・効果音・BGM の傾向を取り出し、「この動画」または「すべての動画」の編集に反映します。「お手本を外す」で元に戻せます
- **公開範囲の既定値。** 設定の「投稿」で、YouTube（公開／限定公開／非公開）と TikTok（全員／相互フォロー／フォロワー／自分のみ）の既定を決められます。投稿画面で動画ごとに変えることもできます
- **画面をシンプルにしました。** サイドバーと上部は「撮影・編集・投稿」の3つだけ。確認は編集画面の中に入り、設定はフッターの歯車（⌘,）から開きます
- **エージェントは確認なしで動きます。** Claude Code は `--dangerously-skip-permissions`、Codex は `--dangerously-bypass-approvals-and-sandbox` で起動します（設定で切り替え可能）

## 不具合の修正

- Claude Code が権限確認を省かずに起動していた問題を修正しました
- 文末の言葉がカットで消えることがある問題、最後の字幕が動画の終わりを越えて字幕の作成が止まる問題を修正しました
- 人物のワイプで頭が切れることがある問題を修正しました
