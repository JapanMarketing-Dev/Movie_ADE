# Solocut 0.1.2

## 不具合の修正

- **インストール済みの Claude Code・Codex などが認識されない問題を修正しました。** Finder やドックから起動したアプリには、ターミナルで設定した PATH（`~/.local/bin`、Homebrew など）が渡らないため、エージェントが見つかりませんでした。ログインシェルの PATH を読み込み（次回の起動のために覚えておきます）、よく使うインストール先も探すようにしました。この PATH は、エージェントのターミナルと、アプリが実行する solocut CLI（判定モデル・サムネイル生成でエージェントを呼ぶ処理）にも使います
