# Solocut 0.1.0

最初の公開版です。動画編集のための ADE（Agentic Development Environment）。

## できること

- **撮影**: 画面・カメラ（複数台）・マイクを、それぞれ別トラックで同時に収録。NG・重要の目印、カンペ。別撮りの素材は取り込むと音声で自動同期
- **1本の素材から3本**: YouTube（16:9 の本編）、TikTok と YouTube Shorts（9:16）を自動で作成。縦型は見どころを選び、顔や画面を追って組み替え、字幕を作り直す
- **テンプレートどおりに AI が編集**: 技術動画（tech）・語り動画（talk）の2系統。手順は `solocut next` が案内し、Claude Code / Codex / Gemini CLI などがアプリ内のターミナルで進める。「動画を完成させて」など用意済みのプロンプト（JSON で変更可）
- **編集**: 無音・言いよどみのカット、日本語の自然な改行の字幕（単語ハイライト）、用語の誤変換の自動修正、解説シーンなど11種類のシーンの型、効果音の自動配置、BGM のダッキング、声の補正、-14 LUFS への調整
- **判定モデル**: カットの採否や字幕、フレーム単位のチェック（カットの境目、セーフエリア、字幕と顔の重なり、画面に映った個人情報）。既定はお使いのエージェントのサブスクで動作し、API キーは不要
- **モザイク**: 画面に映ったメール・電話番号・API キーを自動で検出してモザイク（要確認として一覧に出る）
- **動画でフィードバック**: プレビューを見ながら喋ってペンで囲むと、タイムコード付きの修正指示になってエージェントへ
- **サムネイル**: Codex のサブスク（または API キー）で画像生成し、日本語タイトルは別に合成
- **投稿**: YouTube（ご自身の Google クライアント）への投稿、TikTok は書き出しと投稿画面の案内、X・Threads・Facebook は告知の投稿画面を開く。必ず承認してから投稿
- **アーカイブ**: 過去の動画と timeline.json をいつでも参照・再利用
- **設定はすべて JSON**、自動更新（署名付き）、macOS / Windows / Linux

## 既知の制限

- macOS 版は Apple の公証を受けていません。初回は「システム設定 → プライバシーとセキュリティ → このまま開く」が必要です。更新のたびに、保存したキーを初めて使うときにキーチェーンの許可を一度求められます
- TikTok・Instagram・Threads・Facebook への API 投稿は、各社の審査が通るまで「書き出し＋投稿画面を開く」方式です
- クリックとキー入力の表示（技術動画）は、収録時の入力の記録に未対応のため、今回は手動のみ
- 実機のカメラでの顔追跡と、長時間の収録は、引き続き確認中です。不具合は GitHub の Issues へ
