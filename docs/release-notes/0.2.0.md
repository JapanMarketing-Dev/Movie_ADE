# Solocut 0.2.0

「ネタを思いつく → 撮る → 勝手に編集される → 見る → OK なら投稿される」だけで動画が出せるように、全体を作り直しました。

## 新しい流れ

- **最初に保存先（マスタフォルダ）を決めるだけ。** 「新しい動画を撮る」を押すと、マスタフォルダの中に動画ごとのフォルダ（日付-タイトル）が作られ、すぐ撮影画面に進みます。テンプレート・動画の種類・言語を選ぶ必要はなくなりました
- **範囲を選んで撮影。** 画面全体ではなく、ドラッグで選んだ範囲だけを録画できます（メニューバーや Dock を映さずに済みます）。カメラは複数同時に使え、「メイン（自分）」に選んだカメラの人物は編集で画面の中央に置かれます
- **撮り終わると自動で編集が始まります。** ターミナルを開かなくても、エージェント（Claude Code）が起動して「動画を完成させて」を実行します
- **撮った直後からプレビューが出ます。** 編集の前でも、撮ったままの映像（画面＋カメラ＋マイク）を再生できます。編集が終わると「編集後」の動画に切り替わります
- **見て OK なら投稿。** 投稿画面で「OK・投稿する」を押すと、エージェントがタイトル・説明・タグ（publish.json、すべて AI が JSON で書きます）を確かめて YouTube／TikTok に投稿します。投稿用のプロンプトは設定で変えられます
- **YouTube・TikTok はボタン1つで接続。** 設定の「アカウント」から接続します（YouTube は Google の確認が終わるまで「確認されていないアプリ」の画面が出ます。TikTok は審査中のため、当面は TikTok アプリの下書きに送る形です）
- **サムネイルは動画の内容から。** ChatGPT のサブスク（Codex の画像生成）で作ってもらいます。API キーは不要です
- **イラスト素材はダウンロード不要。** いらすとや などの無料素材を、エージェントが必要なものだけ取得します

## アカウントとアプリ

- Claude Code・Codex のアカウントを複数登録し、フッターから切り替えられます（Ferret と同じ）
- 更新は自動です。新しい版は裏で取得し、次に閉じたときに入ります
- 判定モデルはなくても動きます（初期設定はオフ）。迷うところは AI が判断して「要確認」の印を付けます
- 設定は Ferret と同じ並びの画面になり、settings.json・prompts.json を直接さわる必要はなくなりました。プロンプトは「起動プロンプト」と「投稿プロンプト」の2つだけです

## なくなったもの

- カンペ、技術動画／語り動画の選択、1回の撮影から3本（TikTok・Shorts）を作る機能
- Instagram・X などへの告知、投稿の履歴、過去の動画の画面
- 判定モデル・画像生成の API キーの設定

## 不具合の修正

- 録画直後のプレビューが黒くなる・音と映像が約2分ずれることがある問題を修正しました（マイクの開始時刻の記録の誤り）
- 画面録画の fps が低く判定され、プレビューがカクつく問題を修正しました
