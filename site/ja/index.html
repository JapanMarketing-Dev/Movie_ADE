使い方

ネタ → 撮る → 勝手に編集 → 見る → OK で投稿。

あなたがやるのは、ネタを考えて、撮って、OK を押すことだけ。編集の手順はすべてエージェントが実行するコマンドで、solocut next が「今やること」を常に伝えます。

  1. ネタが浮かぶ

    ホームで新しい動画を作ります。選ぶのは保存する場所だけ。マスタフォルダの中に動画ごとのフォルダができます。

  2. 撮る（範囲を選んで）

    録画する範囲をドラッグで指定するので、メニューバーや Dock は映りません。カメラとマイクも一緒に。

  3. 勝手に編集

    止めると「動画を完成させて」が Claude Code（または Codex など）に自動で送られ、同期・文字起こし・カット・字幕・チェック・書き出し・サムネイルまで進みます。

  4. 見る

    完成した動画を、タイトル・説明・タグと一緒にアプリで確認。直してほしいところはプレビューに喋るだけ。

  5. OK で投稿

    「OK・投稿する」を押すと、エージェントが publish.json を確かめて、アプリ経由で YouTube や TikTok に投稿します。

撮影

撮るのは必要な範囲だけ。カメラも、顔はいつも中央に。

スクリーンショットのように、録画する範囲をドラッグで選びます。入力ごとに別トラックで保存し、カメラが複数あっても「メイン（自分）」のカメラを、顔が中央に来るように切り抜きます。

  • 画面・カメラ・マイク・PCの音声を、同じ時計で同時に収録
  • ミラーレスや iPhone で撮った素材を取り込むと、音声でフレーム単位に自動同期。長尺の時計のズレも補正
  • 録画する範囲はドラッグで指定。メニューバーや Dock は映らない
  • カウントダウンと、話しながら「今のNG」「ここ重要」を残すホットキー
  • 1秒ごとにファイルへ書き込むので、落ちても消えない

テンプレート

テンプレートは1つ。選ぶものはない。

テンプレートは、見た目・プロンプトで書いた編集方針・作業手順をまとめた定義です。Solocut がテンプレートからエージェントへの指示書を生成するので、どのエージェントでも同じ手順・同じ品質基準で仕上がります。

  • 1つのプロジェクトで 16:9 の動画を1本。YouTube にも TikTok にもそのまま
  • 無音・言いよどみ・撮り直しをカットし、メインのカメラから顔が中央に来るように切り抜き
  • クリックした場所への自動ズーム、押したキーの表示、カーソルの強調つき
  • solocut next が手順と合格条件を守らせます
# template.yaml
id: solocut
canvas: { width: 1920, height: 1080, fps: 30 }
layouts: [screen-with-wipe, camera-full, screen-full]
camera: { main: face-centered }
cut:
  silence: { minMs: 300, padMs: 80 }
  fillers: [えー, えっと, あのー]
  retakes: keep-last
captions: { style: default, highlight: word }
audio: { loudness: -14, truePeak: -1 }
checks: [cut-boundaries, caption-safe-area, pii-on-screen]
pipeline:
  [ingest, sync, transcribe, rough-cut, captions,
   layout, preview, check, final, thumbnail, publish]

ターミナル

エージェントも、サブスクも、ターミナルも、いつものまま。

アプリの中で、エージェントのCLIを本物のターミナルとして動かします。タブで切り替えても、状態はプロジェクトのファイルにあるので、別のエージェントがそのまま続きを進められます。

  • どのCLIエージェントでも

    Claude Code、Codex、Gemini CLI、OpenCode、Cursor、GitHub Copilot、独自のコマンドも。

  • 切り替えと引き継ぎ

    使用量の上限に達したら、次のエージェントが引き継ぎメモを読んで続けます。

  • いつも最新

    Solocut 自体は Cloudflare から署名付きで自動更新。エージェントCLIの新しい版もお知らせします。

  • CLIだけでも動く

    solocut はアプリなしでも、手元のターミナルや CI で使えます。

  • すべての編集を戻せる

    編集は操作のログとして残ります。誰が・何を・なぜ変えたかが分かり、いつでも戻せます。

  • 元の素材は書き換えない

    撮った素材は読み取り専用。それ以外はすべて作り直せます。

チェック

大事なフレームは、見る前にチェック済み。

黒コマ、フリーズ、ラウドネス、書き出しの仕様に加え、すべてのカットの前後、字幕の切り替わり、モザイクのフレームを機械的にチェックします。判定モデルで確かめることもできますが、任意で初期設定はオフ。なくても全体が動きます。

モザイク

個人情報は、自動で隠して追いかける。

メールアドレス、通知、APIキー、電話番号、映り込んだ他人の顔やナンバープレートを検出・追跡して、モザイク・ぼかし・塗りつぶしをかけます。範囲は元の素材の座標で持つので、レイアウトを変えても、顔に合わせて切り抜いても、ずれません。

ベンチマーク

URL を貼るだけ。真似るのは動画ではなく、パターン。

Solocut の特長

1人のために作りました。

  • 撮り終われば、編集が始まる

    録画を止めると、起動プロンプト「動画を完成させて」がエージェントに送られます。ターミナルを開く必要も、ほかのプロンプトを選ぶ必要もありません。

  • OK を押したら投稿

    タイトル・説明・タグ・投稿先ごとの設定は、エージェントが publish.json に書きます。OK を押すと同じ動画を YouTube と TikTok のどちらか、または両方へ。連携はそれぞれボタン1つ。

  • 動画の内容からサムネイル

    エージェントが Codex（ChatGPT のサブスク）や Gemini に、動画の内容に合ったサムネイルを描かせます。アプリに API キーは要りません。

  • 過去の動画をいつでも参考に

    完成した動画とその timeline.json をすべて検索できる形で保存。「先月のあの回みたいに」と頼めば、エージェントがその作りに合わせます。

  • 無料・オープンソース

    MIT ライセンス。アカウント登録、透かし、サブスクリプションはありません。

  • 初期設定でプライベート

    動画と音声は端末から出ません。アップロードするのは、あなたが OK した動画だけ。連携したアカウントへ送ります。

  • macOS・Windows・Linux

    3つのOSで同じアプリ、同じ結果。

  • YouTube・TikTok にそのまま

    字幕・チャプター・音量・メタデータ付きの 16:9 動画1本を、YouTube と TikTok のどちらか、または両方へ。

  • 日本語の字幕に強い

    BudouX による自然な改行、単語ハイライト、強調、用語の誤変換の修正。

  • 見たままが仕上がる

    プレビューと本番の書き出しは、同じエンジンで作ります。

よくある質問

本当に無料ですか？

はい。Solocut は MIT ライセンスで、AI のサーバーを持ちません。編集・フィードバック・サムネイルはすべて、すでにお持ちの AI のサブスク（Claude Code、Codex、Gemini CLI）で動き、文字起こしは端末内で行います。API キーは不要です。

今すぐ使えますか？

はい。macOS・Windows・Linux 向けに公開しています。自動で更新され、開発は GitHub で公開しています。

編集の知識は必要ですか？

いりません。撮って話すだけで、テンプレートとエージェントが編集します。あなたは結果を見て直してほしいところを伝えます。

Remotion は必須ですか？

いいえ。書き出しエンジンは FFmpeg です。Remotion はモーショングラフィックス用の追加オプションで、インストール前に利用条件を表示します。代わりに HyperFrames や Revideo も使えます。

どこに投稿できますか？

YouTube と TikTok です。1つのプロジェクトで 16:9 の動画を1本作り、投稿先は publish.json で YouTube・TikTok・両方から選びます（エージェントが書きます）。

勝手に投稿されませんか？

されません。動画を見て OK を押すまで何も投稿しません。OK のあと、エージェントがアプリ経由で、あなたが連携したアカウントに投稿します。
