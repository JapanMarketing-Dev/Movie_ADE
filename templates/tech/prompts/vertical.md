# 縦型の版（TikTok・YouTube Shorts）の作り方（tech）

本編（YouTube）の編集が終わってから、`solocut derive --target tiktok` と `--target youtube-shorts` で縦型の版を作る。derive は区間を自動で選び、画面を 9:16 に組み替え、字幕を縦型のスタイルで作り直す。ここでは、その結果を次の方針で直す（`solocut tl summary --variant tiktok`、`solocut edit … --variant tiktok`）。

## 1本で言うことは1つ
- 本編の中で一番強いコツを1つだけ選ぶ。残りのコツは使わない（別の回のショートの候補として handoff.md に書く）
- 前提の説明（インストール、環境、自己紹介）は使わない。必要なら画面上のテロップで1行（例:「Node 22 以上」）

## 区間の選び方
- 選ぶ区間の優先順位: ① 結果が画面に出る demo、② 数字・Before/After が出る区間、③ 章の結論（summary）、④ よくある誤解を正す一言
- 選ばない区間: 待ち時間、長い打鍵、前の章を知らないと分からない区間（「さっきの」「これ」が何を指すか分からない）、cta、aside
- 区間の外を指す言葉が残ったら、その文ごと外すか、前の文を足して意味が通じるようにする
- 最後の文は言い切りで終える。「〜なんですが」で終わるなら次の文まで含めるか、その文を外す
- 選び直すときは `solocut derive --target tiktok --selection seg_012,seg_003,seg_015 --replace`（最初の区間がつかみになる）

## 冒頭2秒（つかみ）
- **結果を先に見せる**。完成した画面、動いている様子、Before/After のどれか。結果が本編の後半にあるなら、その区間を先頭に置く
- 同時に「何ができるか」を一言で言っている区間を選ぶ（例:「このコマンド1つで型チェックが10倍速くなる」）。言っていなければ、最初の2秒にテロップで入れる
- 「こんにちは」「今日は〜について」から始めない

## 長さ
- TikTok: 30〜90秒、理想は 40〜60秒。Shorts: 60秒以内、理想は 25〜45秒
- 長すぎたら、例の2つ目 → 補足 → 理由の言い換え の順に外す。手順の途中を抜いて結果がつながらなくなる外し方はしない

## 画面（9:16）
- 上に画面、下に顔（split-v）。横の画面を上半分（1080×960）に入れると文字が小さいので、**操作箇所へのズームを常にかける**（倍率 1.6〜2.5。出力で文字の高さ 28px 以上）
- 顔のワイプは使わない（下半分がカメラ）。顔が映っていない区間は画面だけ（screen-full）で、上下を拡大して埋める
- 打鍵は最初の1秒と、打ち終わった全文だけを残す。結果が出た瞬間は最低1秒映す
- 個人情報のモザイクは本編と同じものが残る。縦では拡大されるので、はみ出していないか `solocut frame --variant tiktok` で確かめる

## 字幕・効果音
- 字幕は大きく（1行 10〜12字、2行まで）、単語ごとのハイライト。画面と顔の境目（上下の中央）付近に置き、操作している箇所と重ねない
- 効果音は、つかみ・結果が出た瞬間・数字が出たときに。1本で 4〜8回まで

## TikTok と Shorts の違い
- 既定では Shorts は TikTok と同じ区間を使う（`sameAs: tiktok`）。60秒を超えるなら、Shorts だけ例を外して短くする
- Shorts の冒頭は「本編への入口」になるように、本編のタイトルと同じ言葉を最初の2秒に入れる。説明文に本編へのリンクを書く（`solocut meta set --variant youtube-shorts`）
- TikTok は最後を最初につながるように終える（ループ再生）。最後の言葉の後の間は 0.3秒まで

## 確認
- `solocut render --preview --variant tiktok` → `solocut check --variant tiktok`。Shorts も同じ
- 冒頭と最後の3フレームを `solocut frame --variant tiktok --at <フレーム>` で見て、話の途中から始まっていない・途中で終わっていないこと
