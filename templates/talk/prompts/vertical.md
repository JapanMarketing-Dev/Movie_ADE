# 縦型の版（TikTok・YouTube Shorts）の作り方（talk）

本編（YouTube）の編集が終わってから、`solocut derive --target tiktok` と `--target youtube-shorts` で縦型の版を作る。derive は区間を自動で選び、顔を追って 9:16 に切り出し、字幕を縦型のスタイルで作り直す。ここでは、その結果を次の方針で直す（`solocut tl summary --variant tiktok`、`solocut edit … --variant tiktok`）。

## 1本で言うことは1つ
- 本編の主張のうち、一番強いものを1つだけ選ぶ。理由は3つまで、例は1つ
- 前置き・自己紹介・「今日は〜について話します」は使わない

## 区間の選び方
- 選ぶ区間の優先順位: ① 結論を言い切っている区間（hook / summary）、② 意外な事実・よくある誤解を正す一言、③ 数字が出る区間、④ 具体例、⑤ 感情が動いている区間（笑い、驚き）
- 選ばない区間: 前の章を知らないと分からない区間（「さっきの」「それ」が何を指すか分からない）、cta、aside、言い直しの残り
- 区間の外を指す言葉が残ったら、その文ごと外すか、前の文を足して意味が通じるようにする
- 最後の文は言い切りで終える。「〜なんですが」で終わるなら次の文まで含めるか、その文を外す
- 選び直すときは `solocut derive --target tiktok --selection seg_008,seg_002,seg_011 --replace`（最初の区間がつかみになる）

## 冒頭2秒（つかみ）
- 結論、意外な一言、問いかけのどれか。本編の中で一番強い一文を探して先頭に置く（例:「その努力、9割ムダです」）
- 後ろの文脈がないと誤解を招く一文、煽りすぎる一文は使わない
- 最初の言葉の前の間は 0.1秒まで。最初のフレームから話している状態で始める

## 長さとテンポ
- TikTok: 30〜90秒、理想は 30〜50秒。Shorts: 60秒以内、理想は 20〜40秒
- 文と文の間は 0.1秒前後まで詰める（語頭・語尾の子音は切らない）
- 1つの区間は長くても5秒。長い文は文節の切れ目で分け、寄り（1.15〜1.3倍）と引きを交互にする
- 長すぎたら、例の2つ目 → 補足 → 理由の言い換え の順に外す

## 画（9:16）
- 16:9 から顔を追って切り出す。顔の幅が横幅の 35〜50% になる大きさが基本。頭の上を切りすぎない（目の位置が画面の上から 1/3 付近）
- 図解のシーン（big-number、ranking、bullet-points）は1本で2回まで、1回 2〜4秒。数字や「3つの理由」を言ったときに使う

## 字幕・効果音
- 大きな強調字幕（1行 8〜12字、2行まで、単語ごとのハイライト）。顔の下、顎より下に置き、額・目・口にかけない
- 強調は1字幕に1語。結論の語、数字、否定（「しない」「ムダ」）を優先する
- 効果音は、つかみ・強調語・シーンが出るときに。1本で 6〜10回まで。話し声と重ねない
- BGM は話し声より 18〜22 dB 下げる

## TikTok と Shorts の違い
- 既定では Shorts は TikTok と同じ区間を使う（`sameAs: tiktok`）。60秒を超えるなら、Shorts だけ例を外して短くする
- Shorts は「本編への入口」。説明文に本編へのリンクを書く（`solocut meta set --variant youtube-shorts`）
- TikTok は最後を最初につながるように終える（ループ再生）。最後の言葉の後の間は 0.3秒まで

## 確認
- `solocut render --preview --variant tiktok` → `solocut check --variant tiktok`。Shorts も同じ
- 冒頭と最後の3フレームを `solocut frame --variant tiktok --at <フレーム>` で見て、話の途中から始まっていない・途中で終わっていないこと
