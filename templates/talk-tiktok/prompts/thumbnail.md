# カバー（talk-tiktok）

- 9:16、1080×1920。TikTok は動画内の時刻で指定するので、hook の 2 秒の中から選ぶか、選んだカバー画像を冒頭の数フレームに入れる
- 顔が大きく、表情がはっきりしたフレーム（驚き、真剣、笑顔）。目を閉じかけ・口が半開き・ブレているものは使わない
- 文字は 6〜10 字、2 行まで。hook の一文を短くしたもの（例: 「努力の9割はムダ」）
- 文字は顔に重ねず、顔の上か下に置く。上 220px・下 440px・右 180px のセーフエリアの外に出さない
- プロフィールのグリッド（3:4 で表示される）でも文字が切れないよう、文字は縦の中央 1440px の範囲に収める
- 内容にない誇張は書かない
